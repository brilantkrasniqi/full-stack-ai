# Phase 10: Python and launch (Days 141–150)

Main resources: the [official Python tutorial](https://docs.python.org/3/tutorial/), [uv](https://docs.astral.sh/uv/), [Pydantic](https://docs.pydantic.dev), the [FastAPI tutorial](https://fastapi.tiangolo.com/tutorial/) and the [Anthropic Python SDK](https://github.com/anthropics/anthropic-sdk-python).

### Day 141 · Tue Mar 30 · Python for JavaScript developers

- **Read:** Python tutorial chapters 3–5 (informal introduction, control flow, data structures).
- **Do:** Translate 10 of your old JS utility functions into Python.
- **Tasks:** 20 short exercises: lists, dicts, comprehensions, f-strings, functions with type hints. No classes needed.
- **Done when:** all 20 run.
- **Recall:** List comprehension vs JS `map`/`filter`? How do Python type hints differ from TypeScript?

### Day 142 · Wed Mar 31 · Modern Python tooling

- **Read:** uv getting started. Pydantic "Models" basics. `httpx` async quickstart.
- **Do:** Create a project with uv and add dependencies.
- **Tasks:** Typed script that fetches an API concurrently with `httpx` and validates responses with Pydantic.
- **Done when:** it runs and invalid data raises a clear error.
- **Recall:** Pydantic is to Python as what is to TypeScript?

### Day 143 · Thu Apr 1 · FastAPI + Claude in Python

- **Read:** FastAPI tutorial: first steps, path and query params, request body. Anthropic Python SDK README.
- **Do:** Run the FastAPI auto-generated docs page.
- **Tasks:** Endpoint that takes text, calls Claude with structured output, validates with Pydantic and streams the response.
- **Done when:** it works from the docs page.
- **Recall:** How does FastAPI use type hints? How is the Python SDK different from the TS one?

### Day 144 · Fri Apr 2 · Port an eval to Python

- **Read:** Your Phase 9 harness code.
- **Tasks:** Rewrite your eval runner in Python and confirm the same score.
- **Done when:** both languages agree.
- **Recall:** Which language do you prefer for AI work now, and why?

### Day 145 · Sat Apr 3 · Portfolio site

- **Read:** Look at 5 strong developer portfolios and note what they share.
- **Tasks:** Build your portfolio: every project with a demo video, live link, stack, and eval score where relevant. Make the design stand out.
- **Done when:** the site is live on your own domain.
- **Recall:** What should a hiring manager understand in 10 seconds?

### Day 146 · Sun Apr 4 · Capstone case study

- **Read:** Two engineering case studies you admire.
- **Tasks:** Write the capstone case study: problem, architecture, key decisions, evals, numbers, what you'd do next.
- **Done when:** published on your portfolio.
- **Recall:** What's the single most impressive decision you made?

### Day 147 · Mon Apr 5 · CV and LinkedIn

- **Do:** Sunday mixed quiz, the final one.
- **Tasks:** Update CV and LinkedIn to "Full-stack AI engineer". List TypeScript, React, Next.js, Postgres, Claude API, Agent SDK, MCP, RAG, evals, Python. Frame WordPress work as "shipped production sites for clients."
- **Done when:** both updated and reviewed by Claude for clarity.
- **Recall:** What's your one-sentence pitch?

### Day 148 · Tue Apr 6 · Target roles

- **Read:** 20 job posts closely; note repeated requirements.
- **Tasks:** Save 20 target roles: AI engineer, applied AI, full-stack engineer (AI products), forward deployed engineer. Prefer remote roles and companies shipping AI features.
- **Done when:** a list with links and the requirement each project proves.
- **Recall:** Which requirement appears most often that you're weakest on?

### Day 149 · Wed Apr 7 · Interview practice

- **Do:** Ask Claude to run 2 mock interviews: one technical (system design of your capstone), one behavioral.
- **Tasks:** Practice explaining each project out loud in 2 minutes. Record yourself once.
- **Done when:** you can tell each project's story without notes.
- **Recall:** What question made you hesitate, and what's your better answer?

### Day 150 · Thu Apr 8 · Apply

- **Tasks:** Send the first 10 tailored applications, each linking the project most relevant to that company.
- **Done when:** 10 applications sent.

## After Day 150

- Apply to 5–10 roles a week and keep your current job until an offer is signed.
- Ship one small project every two weeks using whatever Claude released most recently.
- Keep Anki going for 10 minutes a day; your knowledge stays sharp for interviews.
